Date Add / Subtract

Find the date that is N days, weeks, months or years from a start date — before or after. Month-end handling follows standard date arithmetic.

This tool runs entirely in your browser. Your data is never uploaded or stored.

How to use Date Add / Subtract

  1. Pick a start date.
  2. Enter the amount and unit to add or subtract.
  3. Read the resulting date and weekday.
