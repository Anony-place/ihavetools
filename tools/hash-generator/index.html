    Hash Generator

    Compute cryptographic hashes of text or files using the browser’s native Web Crypto API. Output as lowercase hex or Base64.

    Everything is generated or computed locally in your browser with its cryptographic APIs. Nothing is sent anywhere.

    How to use Hash Generator

    1. Paste text or choose a file.
    2. Select an algorithm (SHA-1, SHA-256, SHA-384 or SHA-512) and output format.
    3. Click Compute, then copy the digest.

    Frequently asked questions

    Why is there no MD5?

    Browsers deliberately exclude MD5 from the Web Crypto API because it is broken for security purposes. The SHA-2 family is the modern standard.

    Can I hash a file?

    Yes. Choose a file and it is read as raw bytes and hashed locally — useful for verifying downloads. Nothing is uploaded.
