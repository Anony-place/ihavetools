    JSON Compare

    Compare JSON objects and arrays locally in your browser, ignoring object key order and reporting added, removed and changed values by JSON Pointer.

    Calculations and text processing happen in your browser. Optional share links can contain inputs; see the Privacy Policy.

    How to use JSON Compare

    1. Paste original JSON on the left and revised JSON on the right.
    2. Click Compare JSON; invalid documents are identified separately.
    3. Review added, removed and changed JSON Pointer paths.

    JSON Compare guide

    Compare data rather than formatting

    The tool parses each input, then compares values structurally. Whitespace, indentation and object key order are ignored. Added or removed subtrees appear at their parent path; arrays compare element by element in their original order.

    Example and JSON Pointer paths

    Comparing {"a":1,"items":["x","y"]} to {"items":["x","z"],"a":1,"new":true} reports a changed /items/1 and an added /new. JSON Pointer uses zero-based array indexes; a slash in a key is escaped as ~1 and a tilde as ~0. The empty pointer identifies the root.

    Understand the boundaries

    • A moved array item is not detected as a move; each changed index is reported.
    • Duplicate object keys, unsafe integers, numeric overflow, underflow and negative zero are rejected.
    • JavaScript numbers cannot exactly represent every decimal; use strings or a specialised parser for exact high-precision comparisons.
    • Inputs are limited to one million characters and 256 nesting levels each, with limits of 100,000 visited nodes and 1,000 differences to protect the browser. Long displayed values are shortened.

    Frequently asked questions

    Does object key order matter?

    No. JSON object keys are compared by name regardless of order. Array positions do matter: entries are compared by index.

    Does it detect moved array items?

    No. Array elements are compared by index, so inserting or moving an item can report changes at multiple positions rather than a single move operation.

    Is my JSON uploaded?

    No. Parsing and comparison run locally in your browser. Do not place private JSON in URLs or share screenshots containing sensitive values.

    What are the limits of numeric comparison?

    Duplicate keys, unsafe integers, overflow, underflow and negative zero are rejected. JavaScript floating-point decimals can still round; use strings or a specialised parser when exact numeric fidelity is critical.

    What is JSON Compare used for?

    Compare JSON objects and arrays locally in your browser, ignoring object key order and reporting added, removed and changed values by JSON Pointer.
