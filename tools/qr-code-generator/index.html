    Frequently asked questions

    Do these QR codes expire?

    No. The code contains your text/URL itself (a “static” QR code), with no redirect through any server — it keeps working forever, as long as the destination does.

    How do I make a Wi-Fi QR code?

    Use this exact format as the text: WIFI:S:YourNetworkName;T:WPA;P:yourpassword;; — phones will offer to join the network when scanned. For open networks use T:nopass and leave P empty.

    Which error-correction level should I choose?

    M suits most uses. Higher levels (Q/H) survive more damage, dirt or a logo placed over the code, but make the pattern denser. If you customise colours, keep the code much darker than the background and always test-scan before printing.
