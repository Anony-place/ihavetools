    Morse Code Translator guide

    Morse runs on timing, not just dots and dashes

    Everything is measured in one “unit”: a dot lasts 1 unit, a dash 3 units, the gap between the parts of one letter 1 unit, between letters 3 units, and between words 7 units. The Play button above uses exactly these ratios. That timing is why an experienced operator hears letters as little rhythms (dah-dit-dah = K) instead of counting dots — and why Morse learned by sound sticks far better than Morse memorised from a chart.

    Frequent letters got the shortest codes

    Morse assigned codes by letter frequency in English (he reportedly counted type in a printer’s case): the most common letter, E, is a single dot; T is one dash; then A (·−), I (··), N (−·), S (···) and O (−−−). Rare letters pay full price — J (·−−−), Q (−−·−), Z (−−··). It is, in effect, a 1840s compression scheme: typical English text comes out far shorter than one-symbol-per-letter coding would allow.

    Reading code others wrote

    • Some people write dashes as underscores (_); this translator accepts them when decoding.
    • Without letter gaps, Morse is ambiguous — ·−· could be R, or A+E, or E+N+E. Spacing (or timing) is part of the code, not decoration.
    • International (ITU) Morse — used here — covers A–Z, 0–9 and common punctuation. The original 1844 American Morse from landline telegraphs differs for several letters.

    Frequently asked questions

    What is SOS in Morse code?

    SOS is ··· −−− ··· — three dots, three dashes, three dots. It was adopted as the international distress signal in 1906 because the pattern is unmistakable even through static; that it can be read as “Save Our Souls” is a later backronym, not the origin.

    How are letters and words separated?

    By silence: 3 units of quiet between letters, 7 between words. In writing, this page uses a space between letters and “ / ” between words — and when decoding it also accepts a gap of 3+ spaces as a word break.

    Is Morse code still used?

    Yes, in niches where simplicity wins: amateur (ham) radio operators still work CW (continuous wave) daily, aviation navigation beacons transmit their identifiers in Morse, and it survives as an accessibility input method — a whole message can be sent with a single switch.
