    Frequently asked questions

    Does it support emoji and non-Latin scripts?

    Yes. Text is encoded as UTF-8 before Base64, so any Unicode — emoji, Arabic, Japanese and more — round-trips correctly.

    What is URL-safe Base64?

    It replaces + and / with - and _ so the encoded value can be used in URLs and filenames without extra escaping.
