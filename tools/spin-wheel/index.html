    Spin the Wheel — Random Name Picker

    Add names or choices, spin a prize wheel and get a cryptographically random winner. Shuffle or sort entries, keep a winner history, and remove winners for classroom picks, raffles and elimination draws.

    Calculations and text processing happen in your browser. Optional share links can contain inputs; see the Privacy Policy.

    How to use Spin the Wheel — Random Name Picker

    1. Type one name or option per line — two to 100 entries.
    2. Optionally shuffle the list so the wheel order is not predictable.
    3. Spin, read the winner, then remove that winner if you are running an elimination draw.

    Spin the Wheel — Random Name Picker guide

    Fairness lives in the random index, not the animation

    A physical-looking spin can hide a biased choice, so this wheel does it in the transparent order: a cryptographic random integer chooses the winning entry first; the animation then rotates through five full turns and stops with that segment under the pointer. The segment sizes are equal, and the shuffle uses the Fisher–Yates algorithm — every ordering is equally likely when driven by the same crypto-random source.

    Run a clean raffle or classroom draw

    • Freeze and proofread the entry list before the first spin; duplicates are extra chances unless duplicates are your deliberate weighting system.
    • Announce whether winners stay eligible. Remove winner removes one matching line; remove every duplicate line manually if a name must not win again.
    • The history records the order of winners in this tab — screenshot or copy it before closing if the draw needs an audit trail.
    • For money prizes or regulated promotions, a browser wheel is entertainment software, not a certified draw system; check the promotion rules that apply to you.

    Equal slices, equal probability

    With 8 distinct entries, each has a 1 in 8 (12.5%) chance on any one spin, and past spins do not make an entry “due”. Removing winners changes the pool: after one of 8 is removed, each remaining entry has a 1 in 7 chance on the next spin. That no-replacement rule is what turns repeated spins into a fair ranking of the whole list.

    Frequently asked questions

    Is the wheel really random?

    The winner index is selected before the animation using crypto.getRandomValues with rejection sampling, so every entry has an equal chance and the spin merely lands on the pre-chosen segment. It does not use Math.random.

    Can one name have a higher chance?

    Enter that name on multiple lines. Each line is a separate equal segment, so three lines for one entry give it 3 chances out of the total. Use this intentionally — accidental duplicates also multiply the chance.

    Are my names saved or uploaded?

    No. Entries and winner history exist only in the current tab and disappear on refresh. Copy the list elsewhere if you need the same wheel again later.
