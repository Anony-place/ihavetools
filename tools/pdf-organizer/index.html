    PDF Page Organizer

    Organize pages of a PDF in your browser: reorder pages, remove unwanted pages, rotate individual pages, optionally add page numbers and export a new document without uploading it.

    Your file is processed locally in your browser and is not uploaded.

    How to use PDF Page Organizer

    1. Choose an unencrypted PDF and wait for its numbered page list.
    2. Use the arrow, rotate and remove buttons, or keep ranges, odd or even original pages and reverse the current order; restore the original list if needed.
    3. Optionally add output page numbers, then export a new PDF and review every page before sharing.

    PDF Page Organizer guide

    Organize a PDF by page number

    The list begins in original order. Arrow buttons change output order, rotate adds a clockwise 90-degree turn, and remove excludes a page from the new PDF. The original file remains unchanged. Restore original pages resets the list and all added rotations.

    Add page numbers

    Enable Add page numbers and choose the starting number, position, size and color. The first output page can be left unnumbered; numbering starts on the next page. Numbers follow output order after reordering and rotation. The original is not modified. This adds visible text, not PDF page labels, and does not remove existing numbers. Review every exported page for overlap and contrast.

    Filter or reverse pages

    Enter original page numbers such as 1-3, 7 and apply the filter to keep matching pages from the current list. Odd and even filters also use original page numbers. Existing order and rotations stay intact. Removed pages do not return unless you restore the original list. Reverse changes the current order without changing rotations.

    Example: keep pages 3 and 1

    For a three-page PDF, remove page 2 and move page 3 above page 1. The output contains page 3 first and page 1 second. Rotating page 3 adds to its existing page rotation; it does not change the source file.

    Review before sending

    • Page numbers refer to the original document; this tool does not render previews.
    • Check output carefully for forms, links, bookmarks, attachments and other document-level features that may not survive page copying.
    • A digital signature applies to the original document and will not validate the new copy.
    • Removing a page is not a way to redact content on retained pages. Use a dedicated, verified redaction process for sensitive information.

    Frequently asked questions

    Is my PDF uploaded?

    No. The PDF is read and processed in your browser using the locally loaded pdf-lib library. The document itself is not sent to a server.

    How does page numbering work?

    Optional numbering uses output order and a starting whole number. Choose a top or bottom position, size and black or white text. You can leave the first output page unnumbered; the starting number then appears on the second. Numbers may overlap content or be hard to see; review every exported page. Existing page labels are not removed.

    Can I see page thumbnails?

    No. This organizer lists the original page numbers and output positions rather than rendering thumbnails. Check page numbers in a PDF viewer before organizing.

    Will forms, bookmarks and signatures be preserved?

    Not necessarily. Copying pages into a new PDF can lose document-level features, interactive forms, attachments and bookmarks. Digital signatures will not remain valid. Review the exported document.

    Are encrypted PDFs supported?

    Password-protected PDFs cannot be opened here. Remove protection in an appropriate application first. Files are limited to 200 MB and the organizer supports at most 500 pages.
