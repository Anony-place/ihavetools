Password Generator

Create strong passwords of any length with the character sets you choose. Uses crypto.getRandomValues with unbiased selection, and shows real entropy.

Everything is generated or computed locally in your browser with its cryptographic APIs. Nothing is sent anywhere.

How to use Password Generator

  1. Set the length and toggle character sets (upper, lower, digits, symbols).
  2. Optionally exclude look-alike characters.
  3. Click Generate, then copy. Every password is created locally.

Frequently asked questions

Are the passwords sent anywhere?

No. Passwords are generated in your browser with the Web Crypto API and never leave your device. There is no server component.

What makes these passwords strong?

Length and true randomness. The tool uses unbiased selection from your chosen character sets and reports the entropy in bits — aim for 75+ bits.
