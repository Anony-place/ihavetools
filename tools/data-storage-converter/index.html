    Data Storage Converter guide

    Decimal and binary units are both exact

    Decimal storage units rise by 1000, matching ordinary SI prefixes. Binary units rise by 1024 and have distinct names — kibibyte (KiB), mebibyte (MiB), gibibyte (GiB) and tebibyte (TiB). This converter labels them separately instead of silently choosing one convention.

    Decimal unitBytesBinary unitBytes
    1 KB1,0001 KiB1,024
    1 MB1,000,0001 MiB1,048,576
    1 GB1,000,000,0001 GiB1,073,741,824
    1 TB1,000,000,000,0001 TiB1,099,511,627,776

    Why the gap looks bigger on large drives

    The relative gap compounds at each step: 1 GiB is about 7.37% more bytes than 1 GB. So a drive marketed as 1 TB (one trillion bytes) is 931.32 GiB when the same byte count is expressed in binary units. Nothing has vanished in that calculation — the measuring unit changed. Filesystem metadata, recovery partitions and manufacturer-reserved space can explain any additional difference in free space.

    Bits, bytes and download speeds

    • 1 byte = 8 bits. File sizes use B (MB, GB); connection speeds use bps (Mbps, Gbps).
    • Convert a speed in Mbps to ideal MB/s by dividing by 8: 200 Mbps ÷ 8 = 25 MB/s.
    • A 700 MB download is 5600 megabits. On a perfect 100 Mbps connection that is about 56 seconds; protocol overhead, Wi-Fi loss and server limits make real downloads slower.
    • When a program reports KiB/s or MiB/s, use the binary rows here rather than treating them as KB/s or MB/s.

    Frequently asked questions

    What is the difference between MB and MiB?

    One megabyte (MB) is exactly 1,000,000 bytes. One mebibyte (MiB) is exactly 1,048,576 bytes (1024 × 1024). The “bi” in MiB marks the binary standard, removing the old ambiguity around “megabyte”.

    Why does a 1 TB drive show about 931 GB?

    It is usually a unit-label difference, not missing storage. A 1 TB device provides about 1,000,000,000,000 bytes; divide by 1024³ and that is about 931.32 GiB. Some operating systems calculate in GiB but display the familiar GB label, and formatting/system space can reduce the usable amount further.

    Is 100 Mbps the same as 100 MB/s?

    No. Network speeds use bits (small b), while file sizes normally use bytes (capital B). There are 8 bits in a byte, so 100 Mbps is at most 12.5 MB/s before protocol overhead and real-world losses.
