    PDF Metadata Viewer

    Read selected PDF document info such as title, author, software, dates and page count locally. This does not inspect all metadata or verify authenticity.

    Your file is processed locally in your browser and is not uploaded.

    How to use PDF Metadata Viewer

    1. Choose an unencrypted PDF file up to 20 MiB.
    2. Read the available document-info fields and page count.
    3. Review other sources separately before sharing; this viewer does not remove metadata.

    PDF Metadata Viewer guide

    Check document information

    The viewer reads selected PDF Document Info fields: title, author, subject, keywords, creator, producer and creation and modification dates when available. It also shows the file name, size and page count. PDF parsing is local in your browser.

    Privacy and authenticity limitations

    This is a limited preview, not a forensic audit. XMP, attachments, comments, form data, content and other hidden data are not inspected. Missing fields do not prove the PDF is anonymous or safe. Metadata can be changed and does not prove authorship, dates or authenticity.

    Files and dates

    Choose one PDF up to 20 MiB. Encrypted, damaged or unsupported files may fail. Dates readable by the PDF library are displayed as UTC ISO strings; absent or unreadable fields are identified. Very long fields are truncated; control characters, bidirectional formatting marks and backslashes are escaped in the displayed output. The tool does not modify or remove metadata.

    Why use the iHaveTools PDF Metadata Viewer?

    • Private by design — Your file is processed locally in your browser and is not uploaded.
    • Free to use — no sign-up or automatic branding. Individual tools have file and device limits.
    • Browser-based — use a modern browser on a phone, tablet or computer. Some features depend on browser support and device limits.

    Frequently asked questions

    Does this remove metadata?

    No. The tool is read-only and does not create a cleaned PDF.

    Does it show all hidden information?

    No. It shows selected Document Info fields only, not XMP, attachments, comments or all other metadata.

    Can metadata prove a document is authentic?

    No. Metadata can be edited and is not proof of authorship or dates.

    Does my PDF leave my device?

    No. The selected file is read locally; the PDF library is loaded from this site.

    What is PDF Metadata Viewer used for?

    Read selected PDF document info such as title, author, software, dates and page count locally. This does not inspect all metadata or verify authenticity.
