    Privacy Policy

    Most processing is local. Optional shared links, YouTube thumbnails, browser storage and hosting requests have privacy implications explained below.

    What data the tools process

    Tools run in your browser. Files you select for PDF, image, audio and video processing and text entered into text tools are processed locally rather than uploaded for processing. Browser extensions, operating-system software, screen captures, downloads and services you choose to use separately are outside our control.

    The YouTube thumbnail downloader requests images from YouTube’s CDN (i.ytimg.com). That service receives the requested video ID and normal request information such as your IP address, under its own policies. Opening external links or QR-code actions also contacts their destinations. Code run in the HTML preview can load external resources or send data to other services; only run trusted code and avoid secrets.

    Optional calculator links

    Calculator inputs are not automatically added to the address bar. If you choose “Copy link with inputs”, the resulting link contains your values in its URL fragment. Fragments are not sent in normal HTTP requests, but anyone with the link can read them; they may also remain in browser history, bookmarks, clipboard or sharing apps. Avoid sharing sensitive information. “Copy page link” excludes inputs.

    Older links may contain values in the query string. Opening one sends those values to the host and intermediaries as part of the request and may record them in logs or history. The tool removes known input parameters from the address bar after loading, but cannot erase earlier records or prevent the initial request.

    Accounts and personal data

    There are no user accounts, no sign-up forms and no newsletters. We do not collect names, email addresses or payment details.

    Cookies, local storage and caching

    The site itself sets no cookies. The browser may store the following on your own device:

    • Theme preference — if you switch between light and dark mode, your choice is saved in localStorage so the site remembers it. It never leaves your device.
    • Favourites and recently used — tool IDs are saved in localStorage to display your lists on this device.
    • Offline cache — a service worker caches the site's pages and static files for offline access. Only previously visited pages and resources are available offline; query-string URLs are not saved. It never stores files or text you process with a tool.

    You can clear site data at any time from your browser's site-data settings.

    Analytics and advertising

    iHaveTools currently runs no analytics and no advertising trackers. If privacy-respecting, aggregate analytics or ads are ever added to keep the site free, this policy will be updated first and the change will be visible here with a new date.

    Hosting logs

    The static hosting provider, Vercel, and network intermediaries may log request information such as IP address, URL path, query string, browser and request time under their own policies. We do not control all provider logging or retention. Do not put sensitive information in a query string.

    External links

    Pages may link to external sites (for example, our public code repository). Their privacy practices are their own; this policy covers only iHaveTools.

    Changes and questions

    If this policy changes, the new version will be published on this page with an updated date. Questions are welcome via GitHub issues. See also our Terms of Use.
